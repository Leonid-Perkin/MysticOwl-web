# MysticOwl — Web & PWA приложение раскладов Таро на React

Интерактивное веб-приложение (PWA) на **React + TypeScript + Vite + Tailwind CSS** для проведения раскладов Таро, изучения символики Арканов и ведения журнала раскладов.

## Возможности
- **5 раскладов Таро с позиционной раскладкой на столе**:
  1. **Карта Дня** (1 карта) — энергия и совет на сегодня.
  2. **Нить Времени** (3 карты) — Прошлое • Настоящее • Будущее.
  3. **Зеркало Отношений** (4 карты) — анализ чувств и перспективы союза.
  4. **Перекрёсток Выбора** (5 карт) — сравнение двух вариантов решения.
  5. **Кельтский Крест** (10 карт) — классический расклад со скрещенной второй картой под 90° и вынесением выбранной карты на передний план.
- **Интерактивный стол Таро**:
  - Анимация тасования колоды и реалистичный 3D-переворот карт (CSS 3D transforms + сакральная геометрия рубашки).
  - Поддержка **прямых и перевёрнутых карт** (с визуальным поворотом медальона на 180° и отдельным толкованием теневого аспекта).
  - Фильтр «Только Старшие Арканы» или полная колода.
  - Автоматический **синтез расклада** по балансу стихий (Огонь, Вода, Воздух, Земля, Дух), доле Старших Арканов и итоговому совету.
- **Энциклопедия Арканов**: поиск по названию и ключевым словам, фильтрация по Старшим Арканам и мастям (Жезлы, Кубки, Мечи, Пентакли).
- **Журнал раскладов в LocalStorage**: надёжное локальное сохранение истории раскладов в браузере.
- **PWA (Progressive Web App)**: поддержка установки на смартфон или компьютер прямо из браузера как нативного приложения с поддержкой офлайн-режима.
- **Адаптивный дизайн**: отзывчивый интерфейс для мобильных телефонов, планшетов и широкоформатных экранов с плавной навигацией.

## Стек технологий
- **React 18** + **TypeScript**
- **Vite** — сверхбыстрая сборка и горячая перезагрузка (HMR)
- **Tailwind CSS** — мистическая тёмно-фиолетовая тема с золотыми акцентами
- **Lucide Icons** — чистые векторные иконки для всех символов и стихий
- **Canvas Confetti** — праздничные сакральные частицы при сохранении расклада
- **PWA Service Worker** — автономная работа и мгновенные обновления

## Структура проекта
- `src/main.tsx` — точка входа и регистрация Service Worker.
- `src/App.tsx` — корневой компонент и управление состоянием экранов.
- `src/types/tarot.ts` — TypeScript-типы карт, раскладов, стихий и записей журнала.
- `src/data/tarotDeck.ts` — база Арканов, схемы раскладов и генератор синтеза расклада.
- `src/services/storageService.ts` — сервис работы с LocalStorage браузера.
- `src/components/TarotCardWidget.tsx` — 3D-виджет карты с сакральной геометрией рубашки и анимацией переворота.
- `src/components/CardDetailsModal.tsx` — детальное модальное окно с полным толкованием Аркана.
- `src/components/SacredTablePainter.tsx` — векторный стол с сакральной геометрией и концентрическими орбитами.
- `src/screens/SpreadsCatalogScreen.tsx` — каталог раскладов с баннером и карточками выбора.
- `src/screens/SpreadScreen.tsx` — интерактивный стол для проведения раскладов.
- `src/screens/EncyclopediaScreen.tsx` — справочник всех Арканов с поиском и фильтрами по мастям.
- `src/screens/HistoryScreen.tsx` — журнал сохранённых раскладов с возможностью просмотра деталей.
- `public/` — манифест PWA, иконки логотипа и service worker (`sw.js`).

## Как запустить проект локально

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm run dev
```

### Сборка проекта для продакшена:
```bash
npm run build
```

### Предпросмотр продакшен-сборки:
```bash
npm run preview
```
