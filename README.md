# Astral Tarot — GUI-приложение раскладов Таро на Flutter

Интерактивное кроссплатформенное приложение на **Flutter** (Desktop / Web / Mobile) для проведения раскладов Таро, изучения символики Арканов и ведения журнала раскладов.

## Возможности
- **5 раскладов Таро с позиционной раскладкой на столе**:
  1. **Карта Дня** (1 карта) — энергия и совет на сегодня.
  2. **Нить Времени** (3 карты) — Прошлое • Настоящее • Будущее.
  3. **Зеркало Отношений** (4 карты) — анализ чувств и перспективы союза.
  4. **Перекрёсток Выбора** (5 карт) — сравнение двух вариантов решения.
  5. **Кельтский Крест** (10 карт) — полный классический расклад с пересечением и посохом.
- **Интерактивный стол Таро**:
  - Анимация тасования колоды и 3D-переворота карт (`Matrix4` + `CustomPaint` сакральной геометрии рубашки).
  - Поддержка **прямых и перевёрнутых карт** (с визуальным поворотом медальона на 180° и отдельным толкованием теневого аспекта).
  - Фильтр «Только Старшие Арканы» или полная колода.
  - Автоматический **синтез расклада** по балансу стихий (Огонь, Вода, Воздух, Земля), доле Старших Арканов и итоговому совету.
- **Энциклопедия Арканов**: поиск по названию и ключевым словам, фильтрация по Старшим Арканам и мастям (Жезлы, Кубки, Мечи, Пентакли).
- **Журнал раскладов**: сохранение истории раскладов с вашим вопросом и выпавшими картами.

## Структура проекта
- `lib/main.dart` — точка входа и тема оформления `AstralTarotApp`.
- `lib/models/tarot_card.dart` — модели карт (`TarotCard`, `DrawnCard`, `ArcanaType`, `TarotElement`).
- `lib/models/tarot_spread.dart` — модели раскладов и позиций (`TarotSpread`, `SpreadPosition`, `SavedReading`).
- `lib/data/tarot_deck.dart` — база Арканов, схемы раскладов и генератор синтеза (`TarotRepository`).
- `lib/widgets/tarot_card_widget.dart` — 3D-виджет карты с кастомной отрисовкой рубашки и модальным окном толкования.
- `lib/screens/home_screen.dart` — главное окно с адаптивной навигацией (`NavigationRail` / `BottomNavigationBar`).
- `lib/screens/spread_screen.dart` — интерактивный стол для проведения раскладов.
- `lib/screens/encyclopedia_screen.dart` — справочник всех Арканов с поиском и фильтрами.
- `lib/screens/history_screen.dart` — журнал сохранённых раскладов.

## Как запустить проект
Если у вас установлен Flutter SDK:

```bash
cd /home/leonidperkin/.gemini/antigravity/scratch/tarot_flutter

# Сгенерировать платформенные папки (linux, web, windows, macos, android, ios), если они ещё не созданы:
flutter create .

# Запустить приложение (например, на Linux Desktop или в браузере Chrome):

flutter run -d chrome
```
